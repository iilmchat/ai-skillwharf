# Workflow Orchestrator

Запускай многошаговые цепочки задач через инструмент `run_workflow`.

## Когда использовать

- Нужно последовательно выполнить несколько действий.
- Нужно автоматизировать повторяющийся сценарий.
- Нужно показать пользователю план и результат выполнения цепочки.

## Порядок действий

1. Разбей задачу на короткие шаги и согласуй их с пользователем.
2. Вызови `run_workflow` с массивом `steps`.
3. Верни пользователю цепочку шагов и результат.

## Ограничения

- Не запускай деструктивные команды без подтверждения пользователя.
- Не включай в шаги секреты и токены.
- Инструмент пока работает в режиме заглушки и не выполняет реальные
  команды в песочнице.
