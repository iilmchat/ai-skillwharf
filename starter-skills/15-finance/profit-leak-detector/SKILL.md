# Profit Leak Detector

Ищи утечки прибыли через инструмент `detect_profit_leaks` по реальным данным
MCP: штрафы, удержания за подмены, возвраты, логистика, платное хранение и
ценовой карантин. Вызов платный (Pay-per-Call) и списывается через BAL
только после успешного получения данных.

## Когда использовать

- Нужно понять, почему прибыль ниже ожидаемой.
- Нужно проверить штрафы, габариты и удержания.
- Нужно подготовить список подозрительных списаний.

## Порядок действий

1. Уточни `sellerId` (`shop_id`), маркетплейс и период (по умолчанию 30 дней).
2. Вызови `detect_profit_leaks`.
3. Верни `findings` с суммами и источниками (`wb_deductions`,
   `wb_finance_report`, `ozon_finance_totals`, `wb_prices_quarantine`).
   Если `dataAvailable: false` — данных нет, сообщи об этом.

## Ограничения

- Ozon не отдаёт штрафы отдельной сущностью: используются категории начислений.
- Перед выводами сверяй данные с отчётами маркетплейса.
- При ошибке MCP инструмент возвращает ошибку провайдера, без демо-утечек.
