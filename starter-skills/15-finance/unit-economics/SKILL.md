# Unit Economics

Считай юнит-экономику товара через инструмент `calculate_unit_economics`.
Данные приходят из MCP-серверов Ozon/WB: выручка, заказы, возвраты,
комиссия, логистика, хранение и штрафы. Демонстрационных значений нет.

## Когда использовать

- Нужно понять маржу по конкретному SKU.
- Нужно сравнить экономику нескольких товаров.
- Нужно найти SKU с отрицательной или низкой маржой.

## Порядок действий

1. Уточни SKU и маркетплейс (`ozon` по умолчанию или `wb`).
2. Если известна себестоимость единицы — передай `cost` (для Ozon без неё
   маржа не рассчитывается; для WB маржа = выплата без закупочной стоимости).
3. При необходимости задай `dateFrom`/`dateTo` (YYYY-MM-DD; Ozon — не более
   31 дня, по умолчанию последние 30) и `sellerId` (`shop_id`).
4. Вызови `calculate_unit_economics` и верни маржу, расходы и источники.
   Если `dataAvailable: false` — данных по SKU нет, не выдумывай числа.

## Ограничения

- Ozon не привязывает комиссию/логистику к SKU в начислениях: инструмент
  распределяет общие расходы пропорционально выручке SKU и указывает это в
  `assumptions`.
- Не используй расчёт как единственное основание для изменения цен.
- При ошибке MCP инструмент отдаёт ошибку провайдера, а не фиктивные суммы.
