## 1. One-Pager для ЛПР

### 1.1. Краткое КП

**SkillWharf — управляемый AI-Офис для российского бизнеса.** Это self-hosted
платформа автономных агентов, которая доводит задачу до результата под
контролем человека и работает с корпоративными системами клиента: 1С, ЭДО,
маркировкой, CRM и мессенджерами.

## 2. Чек-лист онбординга Design Partner за 3 дня

### День 1 — Подключение и выбор трека

* [ ] Создать воркспейс и назначить роли owner/admin/operator/viewer (RBAC) и
      лимиты HITL (ABAC).
* [ ] Подключить хранилища: PostgreSQL, Redis, при необходимости Qdrant
      или профиль `qdrant`.
* [ ] Подключить 1С через OData (`ONEC_ODATA_URL`, `ONEC_USERNAME`,
      `ONEC_PASSWORD`) и проверить справочник `Номенклатура`.
* [ ] Выбрать 1–2 отраслевых трека из A–L и зафиксировать сценарии пилота.
* [ ] Подключить мессенджер: Telegram-бот, VK Teams, Пачка или Яндекс
      Мессенджер; проверить входящий webhook.
* [ ] Критерий дня 1: агент видит данные 1С и отвечает по выбранному треку.

### День 2 — Роли, HITL и безопасность

* [ ] Собрать роль в `/app/builder`: системный промпт, навыки, регламент HITL,
      дневной бюджет.
* [ ] Настроить inline-кнопки одобрения в мессенджере и проверить роль
      руководителя.
* [ ] Включить 152-ФЗ PII-маскирование (`PII_MASKING_ENABLED=true`) и проверить,
      что токены восстанавливаются только локально.
* [ ] Подключить Vault или Yandex Cloud KMS (`KMS_PROVIDER=vault|yandex-kms`)
      и проверить ротацию ключей.
* [ ] При работе с ЭДО подключить Диадок/СБИС, при работе с товаром — ГИС МТ
      «Честный ЗНАК».
* [ ] Критерий дня 2: критичное действие останавливается на HITL, ПДн не
      уходят во внешнюю LLM в открытом виде.

### День 3 — Eval-прогон и приёмка

* [ ] Сформировать золотой датасет на 10–20 типовых задач выбранного трека.
* [ ] Запустить Evals через `pnpm evals:validate` и Eval API; проверить
      pass rate не ниже порога (0.85).
* [ ] Включить Smart Model Cascade (`LLM_CASCADE_ENABLED=true`) и Semantic
      Cache; зафиксировать Economics до/после.
* [ ] Настроить Cron-сводку (`SCHEDULER_POLL_MS`, `/app/schedules`) и получить
      первый дайджест в мессенджер.
* [ ] Проверить Knowledge Hub: загрузить регламент, получить ответ с цитатой
      источника.
* [ ] Критерий дня 3: отчёт с метриками качества, экономии и списком
      доработок согласован с ЛПР.

### 2.1. Критерии успешного пилота

| Критерий | Целевое значение |
| --- | --- |
| Pass rate Evals | Не ниже 0.85 |
| HITL | 100% критичных действий требуют одобрения |
| 152-ФЗ | Ноль открытых ПДн в outbound-запросах к LLM |
| Экономия LLM | Не менее 20% на тестовом трафике (цель — 40%) |
| Время внедрения | Не более 3 рабочих дней |

### 2.2. Что подготовить со стороны клиента

* [ ] Доступы к 1С (OData-публикация), ЭДО и ГИС МТ при необходимости.
* [ ] Токен мессенджера и идентификатор чата для уведомлений.
* [ ] 10–20 обезличенных примеров задач для золотого датасета.
* [ ] Ответственного со стороны бизнеса для согласования HITL-регламента.
