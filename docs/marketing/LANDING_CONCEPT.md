# Концепция: AI-офис в SkillWharf (Питч-дек и Лендинг)

**Статус:** Утверждено
**Цель:** Маркетинговая упаковка платформы для инвесторов, клиентов и Open Source сообщества.

## 1. Общая рамка

«AI-офис — это не визуализация ради визуализации, а способ сделать автономных агентов управляемыми в конкретном бизнес-контексте».
Одна платформа — два сценария (Трек А: ПВЗ, Трек Б: Dev-команда).

## 2. Трек А: AI-офис для ПВЗ (Пункт выдачи заказов)

**Портрет клиента:** Владелец 1–3 точек ПВЗ (Ozon, WB, Я.Маркет). Нет IT-штата. Тратит 4-6 часов в день на рутину.
**Боли:**

- «Я не вижу, что делает бот».
- «Возврат требует моего решения».
- «Отчёты — это вечерняя рутина».

**Агенты в офисе (5 мест):**

1. **Кладовщик:** Приёмка, сверка остатков (Стоит у стеллажа).
2. **Оператор выдачи:** Уведомления клиентам (Сидит за телефоном).
3. **Возвраты:** Обработка актов. *Останавливается у «двери» для одобрения спорных случаев.*
4. **Отчётность:** Ежедневная сводка (Стоит у принтера).
5. **Поддержка:** Ответы на FAQ (В «call-центре»).

**Монетизация ПВЗ:**

- Free: 1 точка, 2 агента, 2D-офис.
- Pro: 2 490 ₽/мес за точку (все 5 агентов, real-time WebSocket).
- Pay-per-Call: 50 ₽ за генерацию юридически значимого акта возврата.

## 3. Трек Б: AI-офис для Dev-команды

**Портрет клиента:** Тимлид / CTO команды 5–25 человек. Уже есть GitHub Actions, Sentry, Dependabot, но они разрознены.
**Боли:**

- «Фоновые агенты невидимы».
- «Деплой в прод — это стресс».
- «Контекст теряется».

**Агенты в офисе (5 мест):**

1. **Ревьюер:** Code review (Сидит с лупой).
2. **Дежурный:** Incident response, алерты (Стоит у пульта).
3. **Тестировщик:** Прогон в Sandbox (Работает в стеклянной кабине).
4. **Документатор:** Обновление README (Сидит с блокнотом).
5. **Секьюрист:** Сканирование, skill-vetter (Стоит у турникета).

**Монетизация Dev:**

- Free: 3 агента, до 5 разработчиков.
- Team: 990 ₽/мес за разработчика (real-time, все агенты).
- Pay-per-Call: 100-500 ₽ за генерацию пост-мортема инцидента.

## 4. Ключевые тезисы для Лендинга

1. **Hero:** «Автономные AI-агенты для вашего бизнеса. Управляйте ими визуально».
2. **Проблема:** «Агенты работают, но вы не видите, что происходит».
3. **Решение:** «AI-Офис — живое окно в работу ваших сотрудников».
4. **Human-in-the-Loop:** «Агент не пройдет в дверь "Production" без вашего ключа».
5. **Призыв:** «Разверните свой офис за 15 минут (Docker Compose)».

## 5. Дизайн и Стиль

- Используем брендбук IIRuChating (Material 3).
- Цвета: Primary `#6B38D4`, Tertiary `#0EA5E9`, фон `#FFFFFF` / `#0F172A`.
- Анимации: плавные (Framer Motion), имитирующие работу офиса (печать, пульсация).
