# Руководство пользователя SkillWharf

**Для кого:** сотрудники, которые работают с агентами каждый день: операторы,
менеджеры, аналитики, HR, юристы, контент-команды.

**Обновлено:** 2026-11-14 (Sprint 20).

SkillWharf — рабочее пространство для ИИ-агентов. Вы ставите задачу в чате,
агент выполняет её с помощью подключённых навыков и инструментов, а AI-Офис
показывает, что происходит: кто работает, кто ждёт вашего решения и что уже
готово.

## 1. Первый вход и рабочее пространство

### 1.1. Учётная запись

Учётные записи создаёт администратор платформы: самостоятельной регистрации в
интерфейсе нет. Если доступа нет, напишите администратору свой рабочий email —
он создаст пользователя и сообщит начальный пароль.

### 1.2. Вход

1. Откройте адрес платформы, который выдал администратор.
2. Введите email и пароль на странице входа.
3. После входа вы попадаете в чат.

Сессия восстанавливается при перезагрузке страницы, пока действует
refresh-токен. Если появилось сообщение «Сессия истекла», войдите заново.

### 1.3. Навигация

Слева — основное меню. Набор пунктов зависит от роли.

| Пункт меню | Что внутри |
| --- | --- |
| Чат | Основное рабочее место: задачи, ответы агента, загрузка документов |
| Навыки | Установленные навыки, их версии и стоимость |
| Магазин | Каталог навыков по категориям (установка — администратор) |
| AI-офис | Визуальные статусы агентов, ожидающие подтверждения |
| Финансы | Юнит-экономика и аудит рисков по данным Ozon и Wildberries |
| Настройки | Интеграции, долговременная память, язык |
| Пульт управления | Только для администратора: промпты, LLM-маршруты, навыки, аудит |

Внизу боковой панели видны баланс, счётчик токенов, переключатель языка
(русский/английский), тема оформления и кнопка выхода.

## 2. Чат: как ставить задачи и читать ответы

### 2.1. Соединение и стриминг

Чат работает через постоянное соединение с сервером (WebSocket). В шапке чата
есть индикатор:

- «Подключение…» — соединение устанавливается, отправлять сообщения пока
  нельзя;
- «В сети» — можно работать;
- «Не в сети» — соединение потеряно; подождите, платформа переподключится.

Ответ агента приходит постепенно, по мере генерации: сначала появляется
строка статуса «Ассистент печатает…», затем текст дописывается на глазах. Это
нормальное поведение, а не сбой: длинные ответы так читать удобнее, и видно,
что агент действительно работает.

### 2.2. Как отправить задачу

1. Напишите сообщение в поле внизу и нажмите Enter (или кнопку отправки).
2. Дождитесь, когда ответ перестанет дописываться: пока идёт генерация, поле
   ввода заблокировано.
3. Если ответ оборвался, повторите отправку: сообщение останется в диалоге.

Чем точнее задача, тем лучше результат. Полезно указывать: что нужно сделать,
для кого, в каком формате и объёме, какие данные использовать. Пример:
«Сделай сводку по заказам за неделю в виде таблицы: SKU, выручка, маржа.
Источник — Ozon».

### 2.3. Что умеет показывать чат

| Формат ответа | Как выглядит в чате |
| --- | --- |
| Обычный текст | Абзацы с сохранением переносов |
| Таблица | Настоящая таблица с прокруткой по горизонтали |
| Программный код | Блок с подписью языка и прокруткой |
| Картинка по ссылке | Превью, по клику открывается в полном размере |
| Результат скрининга резюме | Карточки: навыки, опыт, образование, скор, вердикт |

Если агент вернул таблицу, её можно выделить мышью и вставить в Excel или
Google Таблицы. Сырые технические данные (JSON) платформа старается показывать
читаемо: например, разбор резюме — карточками, а не текстом программы.

### 2.4. Диалоги

При каждом входе в чат начинается новый диалог. Сообщения сохраняются в базе,
но список прошлых диалогов в интерфейсе пока не выводится — это ограничение
текущей версии. Если нужен контекст прошлой задачи, приложите документ или
кратко повторите вводные.

## 3. AI-Офис и подтверждение действий (HITL)

### 3.1. Зачем нужен офис

AI-Офис — это наглядная схема работы: карточки агентов за столами. Вместо
«чёрного ящика» вы видите, кто чем занят и кто ждёт вашего решения. Офис
открывается из меню или по кнопке в шапке чата; при переходе из чата
сохраняется привязка к текущему диалогу.

### 3.2. Статусы агентов

| Статус | Значение |
| --- | --- |
| Пьёт кофе | Агент свободен и ждёт задачу |
| Печатает | Агент выполняет задачу прямо сейчас |
| Ждёт одобрения | Агент остановился и ждёт вашего решения |
| Ждёт оплаты | Действие платное и требует подтверждения списания |

На карточке видны имя агента, роль, текущая задача и номер стола. Значок
«Live» означает, что карточка обновляется событиями из чата, а не является
демонстрационной.

### 3.3. Что такое HITL

HITL (Human-in-the-Loop, «человек в контуре») — обязательная пауза перед
рискованным или платным действием. Платформа не отправляет статью, не
списывает деньги за результат и не меняет данные без вашего «да».

Пауза возникает, когда навык требует подтверждения: например, публикация
статьи (`dzen-article`), скрининг резюме (`resume-screener`), разбор договора
(`document-analyzer`), аудит рисков (`fraud-shield-audit`).

### 3.4. Как подтвердить действие

Есть три равнозначных способа:

1. **В чате.** Над полем ввода появляется карточка «Агент ждёт подтверждения»
   с кнопками «Одобрить действие» (или «Одобрить публикацию» для статьи) и
   «Отклонить». Пока идёт отправка решения, кнопки неактивны.
2. **В AI-Офисе.** Нажмите карточку агента со статусом «Ждёт одобрения» —
   справа откроется панель с задачей, сроком ожидания и кнопкой
   подтверждения.
3. **В списке ожиданий.** Над карточками офиса есть блок «Ожидают решения» со
   всеми диалогами, которые ждут вас; кнопка подтверждения работает прямо
   оттуда, открывать диалог не обязательно.

После одобрения агент продолжает работу и дописывает ответ в чат. После
отклонения действие отменяется, а замороженные средства возвращаются на
баланс.

### 3.5. Срок ожидания

Ожидание ограничено по времени (по умолчанию 24 часа). В карточке показан
таймер: «Осталось 23 ч» или «Осталось 30 мин». Когда срок истекает, ожидание
закрывается автоматически, резерв средств снимается, а задачу нужно запустить
заново.

### 3.6. Что видно в офисе, а что нет

Офис показывает живые события текущего диалога. Остальные столы — демонстрация
ролей для пилота: их задачи и статусы не связаны с вашими данными. Названия и
распределение ролей по столам настраиваются в рамках внедрения.

## 4. Баланс, оплата и история операций

### 4.1. Как устроен баланс

Работа агента стоит денег: списываются токены модели и вызовы платных навыков.
В боковой панели два числа:

- **Доступно** — сумма, которой можно пользоваться;
- **Заморожено** — резерв под действия, которые ждут подтверждения
  (Pay-per-Outcome).

Для запуска задачи на балансе должно быть не меньше 0,50 ₽. Если денег не
хватает, платформа честно сообщает об этом и предлагает пополнить баланс.

Отдельно в панели виден счётчик токенов: «израсходовано / дневной лимит».
Лимит защищает от случайных трат; если он исчерпан, дождитесь следующего дня
(счётчик обнуляется по UTC) или попросите администратора изменить лимит.

### 4.2. Как пополнить баланс

1. Нажмите «Пополнить» рядом с балансом.
2. Выберите сумму из быстрых вариантов (100, 500 или 1 000 ₽) или введите свою;
   допустимы копейки.
3. Нажмите «Оплатить» — откроется защищённая страница ЮKassa.
4. Оплатите картой и вернитесь на платформу. При успехе появится сообщение
   «Баланс успешно пополнен!», при отмене — «Оплата отменена».

Деньги зачисляются после подтверждения платежа банком, обычно сразу. Если
баланс не изменился через несколько минут, обновите страницу и проверьте
историю операций: запись «Пополнение» должна появиться в списке.

### 4.3. История операций (Ledger)

Кнопка «История» открывает журнал операций по вашему кошельку. Записи
подгружаются страницами, есть кнопка «Загрузить ещё» и общее количество.

| Тип записи | Что означает |
| --- | --- |
| Пополнение | Деньги поступили на баланс |
| Списание | Оплата выполненной работы (токены, вызов навыка, результат) |
| В ожидании | Средства заморожены под действие, которое ждёт подтверждения |

У каждой записи видно сумму, остаток после операции, описание и дату. Запись
«В ожидании» после вашего решения превращается либо в «Списание» (результат
принят), либо в «Пополнение» (действие отклонено или истекло, резерв
вернулся).

### 4.4. За что именно списываются деньги

- **Токены модели** — за каждый ответ агента, по факту расхода.
- **Pay-per-Call** — фиксированная цена за вызов навыка: например,
  `pdf-extractor` — 30 ₽, `fact-checker` — 30 ₽, `ocr-smart-engine` — 50 ₽,
  `profit-leak-detector` — 300 ₽.
- **Pay-per-Outcome** — цена за принятый результат: `resume-screener` — 50 ₽,
  `dzen-article` — 100 ₽, `document-analyzer` и `fraud-shield-audit` — 500 ₽.
  Деньги резервируются заранее и списываются только после подтверждения.
- **Бесплатные навыки** — поиск по данным маркетплейсов, отправка сообщений в
  Telegram, работа с Google, оркестрация: платите только за токены модели.

## 5. Документы: загрузка, OCR и результаты разбора

### 5.1. Что можно загрузить

Кнопка-скрепка слева от поля ввода открывает панель загрузки. Принимаются:

- **PDF** — договоры, счета, отчёты, резюме;
- **сканы и фото** — PNG, JPEG, WebP.

Ограничения: один файл до 15 МБ. Платформа ограничивает частоту запросов, так
что серия одновременных загрузок может подождать пару секунд. Файл проверяется
до отправки: тип, размер и пустота. Если формат не поддержан, вы увидите
объяснение, а не «неизвестную ошибку».

Файлы DOCX **не загружаются**: документы Word агент создаёт сам (навык
`docx-writer`) и читает в работе, а на вход подавайте PDF или скан. DOCX для
загрузки появится позже.

### 5.2. Как загрузить документ

1. Нажмите скрепку (или перетащите файл в открывшуюся область).
2. Выберите файл. Начнётся отправка, под названием файла появится полоса
   прогресса и проценты.
3. Дождитесь результата разбора. Прогресс 100% означает, что сервер ответил и
   документ разобран, а не просто передан.
4. Если передумали — нажмите «Отменить загрузку», отправка прервётся.

### 5.3. Что показывает результат

Панель результата содержит:

- имя файла, тип и размер;
- **таблицы**, найденные в документе (позиции, суммы, количество);
- **извлечённый текст** в прокручиваемом блоке;
- **предупреждения парсера** — если часть содержимого распознана неуверенно
  или пропущена.

Кнопка «Отправить текст в чат» передаёт распознанное содержимое агенту, и
дальше вы работаете как обычно: «Проверь реквизиты договора», «Найди сумму и
дату», «Сделай сводку по таблице».

### 5.4. Как работает распознавание

- **PDF с текстовым слоем** читается напрямую — быстро и точно, включая
  таблицы.
- **Скан или фото** распознаётся OCR-сервисом. Если администратор подключил
  Smart Document Engine, используется он; иначе — встроенный Tesseract. На
  плохих сканах возможны ошибки и предупреждения.
- **Ошибки формата**: зашифрованный PDF, файл с нестандартными шрифтами или
  «картинка в PDF» без текстового слоя могут дать пустой текст. В этом случае
  сохраните страницы как изображения и загрузите их.

Советы для качественного распознавания: 300 dpi, ровный лист, без бликов,
весь документ в кадре, без обрезанных полей.

### 5.5. Приватность загрузки

Загруженный файл разбирается на сервере и **не сохраняется** как файл: в
системе остаётся только результат разбора в текущем ответе. Если нужен
документ в другом диалоге, загрузите его снова. Подробнее о данных — в
[README раздела безопасности](../security/README.md).

## 6. Интеграции: Telegram, Google, Ozon, Wildberries, Midjourney

Интеграции подключаются в разделе **Настройки → Интеграции**. Каждая карточка
показывает статус: «Подключено», «Не подключено» или «Ошибка». Ключи хранятся
на сервере в зашифрованном виде и после сохранения не показываются — это
нормально.

### 6.1. Telegram

1. Получите токен бота у @BotFather в Telegram.
2. В карточке Telegram вставьте токен формата `123456789:AA…` и нажмите
   «Подключить».
3. Платформа проверит токен и покажет имя подключённого бота.

Подключённый бот используется для исходящих сообщений: уведомлений клиентам,
отчётов, напоминаний. Входящие сообщения в пилоте обслуживает системный бот
платформы — если нужен приём задач в вашем боте, обсудите это с командой
внедрения.

### 6.2. Google Workspace

1. Нажмите «Войти через Google» — откроется страница Google.
2. Выберите аккаунт и подтвердите доступ к Таблицам, Документам и Календарю.
3. Вернитесь на платформу: статус сменится на «Подключено», появится email
   аккаунта.

Доступ можно отозвать в любой момент кнопкой «Отозвать доступ» (или в
настройках безопасности Google). После отзыва агенты перестанут работать с
таблицами, документами и календарём.

### 6.3. Ozon

1. В личном кабинете Ozon Seller создайте API-ключ (Seller API).
2. В карточке Ozon заполните **Client ID** и **API Key**, нажмите
   «Подключить».
3. Платформа проверит ключи и покажет Client ID подключённого магазина.

Ключи нужны для отчётов, цен и аудита рисков. Если в вашем контуре
используются системные ключи маркетплейса, часть запросов может идти под ними —
уточните схему у администратора.

### 6.4. Wildberries

1. В личном кабинете Wildberries создайте токен для категории «Цены и
   скидки» (и отчётов, если нужны).
2. Вставьте токен в карточку Wildberries и нажмите «Подключить».
3. Платформа покажет статус и дату окончания действия токена.

Токен Wildberries действует 180 дней. За месяц до истечения подключите новый,
иначе интеграция перейдёт в статус «Ошибка».

### 6.5. Midjourney (TTAPI)

1. Получите ключ TT-API-KEY у провайдера TTAPI.
2. Вставьте ключ в карточку Midjourney и нажмите «Подключить».

Это неофициальный API Midjourney через посредника: стабильность и сроки
зависят от провайдера. Ключ нужен для навыка генерации изображений.

### 6.6. Общие правила

- Не отправляйте ключи в чат агенту и не пересылайте их коллегам.
- Отзывайте ключи, которые больше не нужны, и при подозрении на утечку.
- Если провайдер отклонил ключ, платформа покажет «Провайдер отклонил ключи.
  Проверьте данные доступа» и оставит интеграцию отключённой.
- Для поиска в интернете (навык `tavily-search`) отдельный ключ пользователю не
  нужен: доступ настраивает администратор платформы.

## 7. Навыки и магазин навыков

Навык — это «профессия» агента: набор инструкций и инструментов. Например,
`resume-screener` умеет разбирать резюме, `dzen-article` — готовить статью,
`unit-economics` — считать экономику товара.

### 7.1. Раздел «Навыки»

Здесь видно, что установлено, версия и автор, включён навык или нет, а также
модель оплаты:

| Модель | Как читать |
| --- | --- |
| Бесплатно | Платятся только токены модели |
| Freemium | Несколько вызовов бесплатно, дальше по тарифу |
| Pay-per-Call | Фиксированная цена за вызов |
| Pay-per-Outcome | Цена за принятый результат, деньги резервируются заранее |
| Подписка | Оплата по подписке |

Управление навыками (установка, включение, удаление) доступно администратору.
Обычный пользователь видит установленные навыки и подсказку, что менять их
может администратор.

### 7.2. Магазин навыков

В магазине навыки сгруппированы по категориям: разработка, коммуникации,
продуктивность, контент, HR, документы, финансы. Есть поиск.

Установка тоже администраторская. При установке платформа предупреждает, если
навык просит опасные права (сеть, файлы, выполнение команд): сначала
показывается окно с перечнем прав, и только после подтверждения навык
устанавливается.

Если нужного навыка нет в списке, запросите его у администратора — набор
расширяется.

## 8. Память агента и кнопка «Забыть меня»

Агент запоминает важные детали диалогов, чтобы не переспрашивать: это
долговременная память. Она хранится в вашем личном пространстве, привязана к
учётной записи и не смешивается с памятью других пользователей.

### 8.1. Просмотр памяти

Если раздел включён администратором, в настройках виден список записей: текст
фрагмента и дата создания. Показываются только ваши записи.

### 8.2. Кнопка «Забыть меня»

**Настройки → Долговременная память → «Забыть меня»** удаляет всю сохранённую
память: текстовые фрагменты и их векторные представления, которые используются
для поиска по смыслу. Действие необратимо: восстановить записи нельзя.

Что важно знать:

- удаляется **только память** — история диалогов, операции по балансу и журнал
  аудита остаются;
- интеграции и подключённые ключи не затрагиваются, их отзывают отдельно;
- для полного удаления учётной записи и связанных данных обратитесь к
  администратору платформы.

Подробный разбор состава данных и требований 152-ФЗ — в
[README раздела безопасности](../security/README.md).

## 9. Коротко для администратора

Администратор (`admin` или `owner`) видит в меню «Пульт управления» —
`/admin`. Там четыре раздела:

| Раздел | Назначение |
| --- | --- |
| Промпты | Шаблоны системных промптов, история версий, создание новой версии |
| LLM Роутер | Правила выбора модели: провайдер, модель, тип задачи, приоритет, дневной лимит стоимости |
| Навыки | Установка и импорт навыков, включение и отключение |
| Аудит | Кто и когда менял настройки платформы |

Кроме того, администратору доступны:

- ручное пополнение баланса пользователя (штатный путь для пользователя —
  ЮKassa);
- управление интеграциями в объёме, разрешённом политикой платформы;
- настройка окружения: ключи провайдеров, лимиты, срок ожидания подтверждений,
  папка документов для агентов.

Операционные процедуры (развёртывание, резервные копии, мониторинг) описаны в
[Runbook развёртывания](../operations/Deployment-Runbook.md).

## 10. Если что-то пошло не так

| Симптом | Вероятная причина | Что делать |
| --- | --- | --- |
| «Сессия истекла» | Истёк срок сессии | Войдите заново |
| «Недостаточно средств» | На балансе меньше 0,50 ₽ | Пополните баланс |
| «Дневной лимит токенов исчерпан» | Израсходован суточный лимит | Подождите до следующего дня (UTC) или попросите администратора изменить лимит |
| «Все LLM-провайдеры недоступны» | Провайдер модели отвечает ошибкой | Повторите через минуту; если не проходит — сообщите администратору |
| «Не удалось связаться с сервером» | Нет сети или API недоступен | Проверьте соединение и повторите |
| «Сервис маркетплейса временно недоступен» | Ozon/WB не отвечает | Повторите позже, проверьте статус интеграции |
| «Файл больше допустимого размера» | Файл превышает 15 МБ | Уменьшите файл или разбейте его на части |
| «Тип не поддержан» | Загружен DOCX, архив или другой формат | Сохраните документ как PDF или загрузите страницы картинками |
| «Файл пуст» | Выбран пустой файл | Проверьте файл на диске и выберите снова |
| «Текст не распознан» | Скан без текстового слоя или плохое качество | Загрузите страницы картинками в лучшем качестве |
| Агент ждёт одобрения, но задача не двигается | Ожидание истекло | Запустите задачу заново |
| Кнопки подтверждения неактивны | Решение уже отправляется | Подождите пару секунд |
