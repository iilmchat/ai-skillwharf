# Трек I: Интеллектуальная обработка документов (OCR & RAG)

**Статус:** Утверждено
**Дата:** 2026-11-13

## 1. Портрет клиента

Юридический отдел, бухгалтерия или enterprise, которым нужно извлекать данные из сканов и PDF.

## 2. Боли

- «PDF-файлы не читаются поиском».
- «Сканы плохого качества не распознаются обычным OCR».
- «Нужен умный поиск по архиву документов».

## 3. Навыки (Инструменты)

1. **pdf-extractor:** Извлечение текста и таблиц из PDF.
2. **ocr-smart-engine:** Подключение к российским OCR (Smart Document Engine) для сканов.
3. **docx-writer:** Генерация отчетов в Word.
4. **document-analyzer:** RAG-поиск по базе документов.

## 4. Демо-сценарий

09:00 — Загрузка 50 PDF-договоров.
09:05 — OCR распознает сканы и извлекает суммы и даты.
09:15 — RAG-поиск находит договоры с упоминанием конкретного контрагента.

## 5. Монетизация

- **Enterprise:** Годовая лицензия от 300 000 ₽ (On-Premise).
- **Pay-per-Call:** 50 ₽ за страницу распознанного документа.
