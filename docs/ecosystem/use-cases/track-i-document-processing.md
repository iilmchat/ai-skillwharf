# Трек I: Интеллектуальная обработка документов

**Статус:** Утверждено
**Дата:** 2026-11-13

## 1. Контекст

Работа с документами (PDF, DOCX, OCR) — самая горячая ниша в РФ (кейсы Росагролизинга, ВЭБ.РФ).

## 2. Навыки (Skills)

1. **pdf-extractor:** Извлечение текста и таблиц.
2. **ocr-smart-engine:** Подключение к российскому Smart Document Engine (230 типов документов).
3. **docx-writer:** Генерация отчетов и резюме.
4. **document-analyzer:** RAG-поиск по документам и ответы на вопросы.

## 3. Монетизация

- **Pay-per-Call:** За каждый распознанный документ.
- **Enterprise:** Лицензия для корпоративных баз знаний.
