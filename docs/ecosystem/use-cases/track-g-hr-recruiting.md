# Трек G: ИИ-Рекрутер для массового подбора

**Статус:** Утверждено
**Дата:** 2026-11-13

## 1. Портрет клиента

HR-директор или рекрутер, обрабатывающий сотни резюме в день (ритейл, логистика, поддержка).

## 2. Боли

- «Воронка огромная, руки не доходят до всех».
- «Время найма затягивается на недели».
- «Нужно гарантировать, что финальное решение принимает человек».

## 3. Агенты в офисе

1. **Скринер:** Анализирует резюме по ключевым словам (resume-screener).
2. **Интервьюер:** Проводит первичный опрос по скрипту (interview-bot).
3. **Координатор:** Назначает встречи с рекрутером (google-workspace).
4. **Рекрутер (HITL):** Проводит финальное интервью (одобрение).

## 4. Особенность Эскроу (Pay-per-Outcome)

Клиент платит только тогда, когда кандидат *успешно дошел до финального интервью*. Деньги замораживаются (Hold) при старте скрининга и списываются (Capture) только после подтверждения.

## 5. Монетизация

- **Free:** До 20 резюме/мес.
- **Pro:** 9 900 ₽/мес.
- **Pay-per-Outcome:** 50 ₽ за каждого кандидата, дошедшего до финального интервью.
