# Трек H: Управление жизненным циклом договоров

**Статус:** Утверждено
**Дата:** 2026-11-13

## 1. Портрет клиента

Юридический отдел, финансовая служба или крупный enterprise с большим потоком договоров.

## 2. Боли

- «Договоры теряются между отделами».
- «Нет прозрачного статуса: кто сейчас смотрит документ».
- «Строгие требования к изоляции данных (152-ФЗ)».

## 3. Агенты в офисе (Процесс)

1. **Секретарь:** Регистрирует входящий договор и отправляет на проверку (workflow-orchestrator).
2. **Юрист:** Анализирует правовые риски (document-analyzer).
3. **Финансист:** Проверяет суммы и условия оплаты (unit-economics).
4. **Директор (HITL):** Подписывает финальную версию (requiresApproval).

## 4. Особенность

Строгая изоляция в Firecracker Sandbox. Данные не покидают контур (On-Premise).

## 5. Монетизация

- **Enterprise:** Годовая лицензия от 500 000 ₽ (On-Premise, интеграция с 1С).
- **Pay-per-Outcome:** 500 ₽ за успешно проведенный через все согласования договор.
