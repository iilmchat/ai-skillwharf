# Трек A: AI-Офис для ПВЗ

**Статус:** Утверждено
**Дата:** 2026-11-13

## 1. Портрет клиента
Владелец 1–3 точек ПВЗ (Ozon, WB, Яндекс Маркет). Нет IT-штата. Тратит 4–6 часов в день на рутину.

## 2. Боли
- «Я не вижу, что делает бот».
- «Возврат требует моего решения».
- «Отчёты — это вечерняя рутина».

## 3. Агенты в офисе
1. **Кладовщик:** Приёмка, сверка остатков (google-workspace, cron-automation).
2. **Оператор выдачи:** Уведомления клиентам (messenger-connector).
3. **Возвраты:** Обработка актов (workflow-orchestrator). *Требует HITL (Pay-per-Outcome) для спорных случаев.*
4. **Отчётность:** Сводка для маркетплейса (cron-automation).
5. **Поддержка:** Ответы на FAQ (tavily-search, messenger-connector).

## 4. Демо-сценарий
08:00 — Отчетность отправляет сводку в Telegram.
10:30 — Оператор выдачи рассылает уведомления о прибытии.
14:00 — Возвраты формируют акт, но ждут одобрения (HITL) в AI-Офисе.
18:00 — Кладовщик находит расхождение (красный статус стола).
20:00 — Отчетность отправляет итоговый отчет.

## 5. Монетизация
- **Free:** 1 точка, 2 агента, 2D-офис.
- **Pro:** 2 490 ₽/мес за точку (все агенты, real-time).
- **Pay-per-Outcome:** 50 ₽ за успешно оформленный спорный возврат.
