# Трек A: AI-Офис для ПВЗ

## Портрет клиента

Владелец 1–3 точек ПВЗ (Ozon, WB, Яндекс Маркет). Нет IT-штата. Тратит 4–6 часов в день на рутину.

## Боли

- «Я не вижу, что делает бот».
- «Возврат требует моего решения».
- «Отчёты — это вечерняя рутина».

## Агенты в офисе

1. **Кладовщик:** Приёмка, сверка остатков (google-workspace, cron-automation).
2. **Оператор выдачи:** Уведомления клиентам (messenger-connector).
3. **Возвраты:** Обработка актов (google-workspace, workflow-orchestrator). *Требует HITL для спорных случаев.*
4. **Отчётность:** Сводка для маркетплейса (cron-automation).
5. **Поддержка:** Ответы на FAQ (tavily-search, messenger-connector).

## Демо-сценарий

08:00 — Отчетность отправляет сводку.
10:30 — Оператор выдачи рассылает уведомления.
14:00 — Возвраты формируют акт, но ждут одобрения (HITL).
18:00 — Кладовщик находит расхождение (красный статус).
20:00 — Отчетность отправляет итоговый отчет.
