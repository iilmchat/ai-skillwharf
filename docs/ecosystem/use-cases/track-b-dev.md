# Трек B: AI-Офис для Dev-команды

**Статус:** Утверждено
**Дата:** 2026-11-13

## 1. Портрет клиента
Тимлид / CTO команды 5–25 человек. Использует GitHub Actions, Sentry, Dependabot.

## 2. Боли
- «Фоновые агенты невидимы».
- «Деплой в прод — это стресс».
- «Контекст теряется».

## 3. Агенты в офисе
1. **Ревьюер:** Code review, анализ диффов (github, workflow-orchestrator).
2. **Дежурный:** Incident response, алерты (cron-automation, messenger-connector).
3. **Тестировщик:** Прогон тестов в Sandbox (workflow-orchestrator, code-runner).
4. **Документатор:** Обновление README (github, read_file).
5. **Секьюрист:** Сканирование, skill-vetter (skill-vetter, tavily-search).

## 4. Демо-сценарий
02:14 — Дежурный получает алерт, стол краснеет.
02:18 — Дежурный создает задачу Ревьюеру (линия связи).
02:25 — Ревьюер подтверждает проблему. План отката ждет одобрения (дверь Production).
08:00 — Тимлид одобряет откат.
08:05 — Документатор пишет пост-мортем.

## 5. Монетизация
- **Free:** 3 агента, 5 разработчиков.
- **Team:** 990 ₽/мес за разработчика.
- **Pay-per-Call:** 100–500 ₽ за генерацию пост-мортема или глубокий аудит зависимостей.
