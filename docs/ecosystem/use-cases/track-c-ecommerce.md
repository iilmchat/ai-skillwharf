# Трек C: AI-Офис для интернет-магазина и маркетплейсов (Ozon/WB)

**Статус:** Утверждено
**Дата:** 2026-11-13

## 1. Портрет клиента
Владелец интернет-магазина или селлер на Ozon/WB (команда 1–3 человека).

## 2. Боли
- «Вопросы и отзывы копятся».
- «Карточки товаров — отдельная работа».
- «Три вкладки для управления магазином».

## 3. Агенты в офисе
1. **Диспетчер:** Маршрутизация задач (workflow-orchestrator).
2. **Поддержка:** FAQ + статус заказа (messenger-connector).
3. **Каталогизатор:** Создание карточек, SEO (ozon_mcp, wb_mcp).
4. **Рекламный:** Объявления и акции (workflow-orchestrator, cron-automation).
5. **Аналитик:** Продажи и остатки (cron-automation).

## 4. Особенность MCP
Интеграция через MCP-серверы (ozon-seller, wb-seller). Human-in-the-Loop (HITL) для изменения цен и ответов на жалобы.

## 5. Демо-сценарий
08:00 — Аналитик собирает сводку продаж.
09:30 — Поддержка отвечает на 15 вопросов (сложные — на одобрение).
11:00 — Каталогизатор обновляет 3 карточки (ждет одобрения).
14:00 — Рекламный предлагает акцию.
18:00 — Итоговый отчет.

## 6. Монетизация
- **Free:** 2 агента, 1 канал.
- **Pro:** 3 990 ₽/мес (до 3 каналов).
- **Pay-per-Call:** 100–300 ₽ за кросс-площадочную аналитику.
