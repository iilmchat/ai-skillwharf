# Трек L: AI-Офис для производства и сборки (Битрикс24 + МойСклад)

**Статус:** Утверждено
**Дата:** 2026-11-17

## 1. Портрет клиента

Владелец небольшого производства (мебель, одежда, сборка электроники). Продажи в Битрикс24, закупки комплектующих и готовая продукция в МойСкладе.

## 2. Боли

- **«Спецификации вручную»:** Менеджеру нужно вручную собрать спецификацию комплектующих для заказа. Долго и чревато ошибками.
- **«Дефицит комплектующих»:** В процессе согласования выясняется, что нужных деталей нет на складе.
- **«Сложный учет»:** Нет сквозной картины от заявки до закупки.

## 3. Агенты в офисе (4 места)

1. **Инженер-конфигуратор:** Автоматически формирует спецификацию (перечень комплектующих) из МойСклада в сделке.
2. **Снабженец:** Проверяет наличие на складе. Если не хватает — создает «Заказ поставщику» в МойСкладе.
3. **Технолог:** Прикрепляет к сделке технологическую карту сборки.
4. **Контролер качества (HITL):** Перед отгрузкой запрашивает подтверждение качества у мастера. Только после этого создает реализацию.

## 4. Демо-сценарий

08:00 — Заказ на шкаф. Инженер формирует спецификацию.
08:05 — Снабженец видит дефицит детали и создает заказ поставщику.
17:00 — Мастер подтверждает качество (HITL), агент формирует отгрузку.

## 5. Монетизация

- **Free:** 1 заказ в день.
- **Pro:** 3 990 ₽/мес за производство.
- **Pay-per-Outcome:** 100 ₽ за успешный заказ (спецификация + контроль качества).
