# Трек D: AI-Офис для маркетингового агентства

**Статус:** Утверждено
**Дата:** 2026-11-13

## 1. Портрет клиента

Оператор или студия (1–5 человек), обслуживающая 5–15 клиентов.

## 2. Боли

- «Контекст клиента теряется (tone of voice, бренд-гайды)».
- «Рутина съедает творчество».
- «Обратная связь медленная».

## 3. Агенты в офисе

1. **Диспетчер:** Маршрутизация (workflow-orchestrator).
2. **Копирайтер:** Тексты, статьи (tavily-search, dzen-article).
3. **Дизайн-промптинг:** Генерация визуалов (midjourney_api).
4. **SEO:** Аудит и семантика (tavily-search).
5. **Аккаунт-менеджер:** Связь с клиентом (messenger-connector).

## 4. Особенность

Изоляция workspace для каждого клиента. Бренд-гайды и tone of voice хранятся отдельно.

## 5. Демо-сценарий

09:00 — Задачи раскладываются на доске.
09:30 — SEO запускает аудит для Клиента А (ждет одобрения).
11:00 — Копирайтер пишет 3 статьи для Клиента Б.
14:00 — Дизайн-промптинг генерирует 5 визуалов для Клиента В.

## 6. Монетизация

- **Free:** 1 клиент, 2 агента.
- **Pro:** 4 990 ₽/мес (до 10 клиентов).
- **Pay-per-Call:** 200–1000 ₽ за SEO-аудит или генерацию визуалов.
