# Трек J: Финансовый аналитический агент (для агентств и селлеров)

**Статус:** Утверждено
**Дата:** 2026-11-13

## 1. Портрет клиента

Аккаунт-менеджер или финансовый контролер в маркетинговом агентстве, который ведет нескольких селлеров на Ozon и WB.

## 2. Боли

- «Я не вижу, где именно утекает прибыль клиента».
- «Клиент спрашивает "почему упала маржа?", а я не могу ответить за 5 минут».
- «Я не успеваю отслеживать риск санкций».

## 3. Навыки (Skills)

1. **unit-economics:** Расчёт реальной прибыли с единицы товара (комиссии, логистика, хранение, возвраты, ДРР, налоги).
2. **profit-leak-detector:** Поиск аномалий в логистике, штрафов, необоснованных списаний.
3. **price-monitor:** Отслеживание цен конкурентов и рекомендация цены «без ухода в минус».
4. **fraud-shield-audit:** Аудит риска санкций (сопоставление всплесков заказов с рекламой, проверка UTM/ERID).

## 4. Демо-сценарий

08:00 — Агент собирает данные из кабинетов (Ozon, WB), формирует дайджест.
08:15 — Менеджер открывает офис и видит готовые рекомендации по каждому клиенту.
11:00 — fraud-shield-audit предупреждает о неполном доказательном пакете.
17:00 — Агент формирует отчёт с фокусом на прибыль, а не просто выручку.

## 5. Монетизация

- **Free:** Базовый unit-economics для 1 клиента.
- **Pro:** 6 990 ₽/мес (все финансовые навыки, до 10 клиентов).
- **Pay-per-Call:** Глубокий profit-leak-detector (300–800 ₽ за операцию).
- **Enterprise:** White-label + интеграция с 1С.
