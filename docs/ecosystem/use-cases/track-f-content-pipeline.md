# Трек F: Мультиагентный контент-конвейер (Дзен и соцсети)

**Статус:** Утверждено
**Дата:** 2026-11-13

## 1. Портрет клиента

Контент-маркетолог, SMM-менеджер или медиа-команда. Нужно выпускать много качественного контента (статьи Дзен, посты VK/TG) быстро и без галлюцинаций.

## 2. Боли

- «Текст пишется часами, а обложку подобрать некому».
- «Нейросети выдают "текст", а не готовый продукт».
- «Галлюцинации ИИ убивают доверие аудитории».

## 3. Агенты в конвейере

1. **Тренд-хантер (SEO):** Ищет инфоповоды и семантику (tavily-search, seo-optimizer).
2. **Копирайтер:** Пишет статью 3000–8000 знаков (dzen-article, telegram-article).
3. **Факт-чекер:** Проверяет факты по первоисточникам (fact-checker, tavily-search).
4. **Редактор (HITL):** Человек утверждает финальный текст. Агент ждет за "дверью" (requiresApproval).

## 4. Демо-сценарий

09:00 — Тренд-хантер находит тренд.
09:05 — Копирайтер генерирует черновик.
09:10 — Факт-чекер подсвечивает сомнительный факт.
09:15 — Человек (шеф-редактор) одобряет статью в AI-Офисе.
09:20 — Статья и обложка готовы к публикации.

## 5. Монетизация

- **Free:** 1 статья в день.
- **Pro:** Подписка на «Контент-отдел» (4 990 ₽/мес).
- **Pay-per-Outcome:** 100 ₽ за статью, готовую к публикации (оплата после одобрения человеком).
