# Roadmap: Переход от MVP к Production (Post-MVP)

**Статус:** Утверждено
**Дата:** 2026-11-13
**Контекст:** По результатам независимого аудита мы переходим от стадии «убедительный демонстратор» к стадии «боевой продукт для пилота». Главные приоритеты — безопасность (изоляция песочницы), замкнутая монетизация (реальные платежи) и стабильность (Auth, память).

## Спринт 9: Production Readiness (Текущий)

*Закрываем критические уязвимости из аудита.*

- [ ] **Безопасность Auth:** Настроить rate-limit для login/register (Throttler), подключить `helmet` и строгий CORS.
- [ ] **Стабильность UI:** Починить разлогин при F5 (сохранение refresh-токена в `localStorage`/`sessionStorage` и авто-обновление).
- [ ] **Изоляция Sandbox:** Вынести Docker Socket из API в отдельный микросервис `sandbox-worker` (ADR-0005).
- [ ] **Замкнуть Биллинг:** Закрыть бесплатный `topup` (сделать admin-only), внедрить списание за токены LLM (Cost Guardrails).
- [ ] **Безопасность Webhooks:** Добавить проверку подписи/IP для вебхуков ЮKassa.

## Спринт 10: Замена Mock-инструментов на Реальные

*Превращаем витрину навыков в реальные бизнес-инструменты.*

- [ ] **Реальный Дзен:** Подключить API Дзена для автоматической публикации статей (сейчас только локальный Markdown).
- [ ] **Реальный MCP:** Подключить настоящие MCP-серверы для Ozon (151 инструмент) и WB (202 инструмента), убрать mock-заглушки.
- [ ] **Реальные LLM:** Написать адаптеры для GigaChat (OAuth + прокси) и YandexGPT (URI). Реализовать полноценный LLM Router с fallback-цепочками.
- [ ] **Реальные интеграции:** Подключить Telegram Bot API (messenger-connector) и Google Workspace API.

## Спринт 11: Масштабирование и Долговременная память

*Готовим платформу к высоким нагрузкам.*

- [ ] **Долговременная память (RAG):** Внедрить `pgvector` для хранения эмбеддингов. Агент должен помнить контекст не только последних 10 сообщений, но и всю историю (долговременная память).
- [ ] **Firecracker:** Перевести Sandbox с Docker на микро-VM Firecracker для аппаратной изоляции (ADR-003).
- [ ] **State Graph Checkpointer:** Сохранять состояние LangGraph в БД (PostgreSQL/Redis), чтобы незавершенные approvals не терялись при рестарте API.

## Спринт 12: Observability и Масштабирование

*Обеспечиваем надежность.*

- [ ] **Мониторинг:** Развернуть Prometheus + Grafana для отслеживания токенов, стоимости (FinOps) и ошибок LLM.
- [ ] **Очереди задач:** Перевести фоновые задачи на Redis/BullMQ (для нескольких реплик API).
- [ ] **Sentry/OTel:** Подключить трейсинг ошибок и распределенную трассировку.

## Спринт 13: Экосистема и Реестр

*Строим маркетплейс.*

- [ ] **Публичный реестр:** Развернуть API для публикации навыков (аналог npm).
- [ ] **Криптографические подписи:** Внедрить проверку подписей навыков (Ed25519), чтобы гарантировать авторство.
- [ ] **Revenue Share:** Реализовать сплитование платежей ЮKassa (85% автору / 15% платформе).

## Сознательно отложено (Не делать сейчас)

- A/B-тестирование промптов (сложно, не критично).
- White-label визуализация (для Enterprise).
- Собственный агентный фреймворк (используем LangGraph).
