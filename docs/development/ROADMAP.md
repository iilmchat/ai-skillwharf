# Roadmap проекта SkillWharf

Этот документ является единым источником истины для отслеживания прогресса. Агенты (OpenCode, Infra) обязаны отмечать выполненные задачи символом `[x]`.

## Спринт 1: Инфраструктура и БД (Текущий)

* [x] Инициализация монорепозитория и CI (pnpm, GitHub Actions).
* [x] Настройка Docker (API + PostgreSQL) и базовой песочницы.
* [x] Реструктуризация документации.
* [ ] Настройка ORM (Prisma) и схемы БД (`User`, `Session`, `Transaction`).
* [ ] Реализация эндпоинта `/health` (проверка БД).
* [ ] Настройка скрипта миграций `db:migrate`.

## Спринт 2: Аутентификация и Безопасность

* [ ] Модуль регистрации пользователей (Email + Password, Argon2).
* [ ] Модуль логина и выдачи JWT (Access + Refresh).
* [ ] Middleware для защиты эндпоинтов (Guards в NestJS).
* [ ] Базовая настройка RBAC (роли `admin`, `user`).

## Спринт 3: Агентный Рантайм (Core)

* [ ] Интеграция LangGraph в NestJS.
* [ ] WebSocket-хаб для общения с агентами.
* [ ] Интеграция с LLM (OpenAI-совместимый фасад, GigaChat/YandexGPT).
* [ ] Сохранение истории сессий и сообщений в БД.

## Спринт 4: Система расширений (Sandbox)

* [ ] Загрузка и валидация `SKILL.md` (Zod-схемы).
* [ ] Интеграция с Sandbox Provider (Docker API для запуска плагинов).
* [ ] Тестовый запуск простого Skill в изолированной среде.

## Спринт 5: Биллинг и Ledger

* [ ] Реализация Billing Abstraction Layer (интерфейсы).
* [ ] Модуль ЮKassa (адаптер).
* [ ] Внедрение Paywall (блокировка вызова Skill без баланса).
* [ ] Запись транзакций в Append-only Ledger.
