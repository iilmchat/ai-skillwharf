# Контекст проекта SkillWharf для AI-агентов

**Текущая версия:** 0.1.0
**Статус:** Документация готова, начато написание кода ядра.

## Что уже сделано

1. Спроектирован Hub-and-Spoke (ADR-001) и технологический стек (ADR-002).
2. Описана спецификация навыков (Manifest-Specification.md).
3. Спроектирован биллинг (Hold -> Capture, Ledger).
4. Разработана Threat Model (изоляция в Firecracker).
5. Настроен монорепозиторий, CI, базовый Docker (API + Postgres).

## Что предстоит сделать (Roadmap)

1. Реализовать эндпоинты `/health` и скрипт миграций БД.
2. Подключить ORM (Prisma/TypeORM) и создать схему БД (User, Session, Transaction).
3. Реализовать базовую аутентификацию (JWT, Refresh tokens).
4. Разработать WebSocket-хаб для связи с мессенджерами.
5. Написать тесты (unit + e2e) для всех модулей.

## Ограничения

- Не менять архитектуру без ADR.
- Не добавлять новые библиотеки без обсуждения.
- Код писать на TypeScript (strict), используя NestJS.
