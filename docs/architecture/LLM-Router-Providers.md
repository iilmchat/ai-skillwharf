# Специфика провайдеров LLM (YandexGPT и GigaChat)

**Статус:** Утверждено
**Дата:** 2026-11-13

## 1. YandexGPT (Yandex AI Studio)

- **Совместимость:** Широкая. OpenAI-совместимые эндпоинты (Chat, Embeddings).
- **Особенность (URI):** Модель задается не просто именем, а URI: `gpt://<идентификатор_каталога>/<имя_модели>`.
- **Авторизация:** IAM-токен живёт 12 часов. Если заданы `YANDEX_OAUTH_TOKEN` и `YANDEX_FOLDER_ID`, адаптер сам обменивает OAuth-токен на IAM (`POST https://iam.api.cloud.yandex.net/iam/v1/tokens`) и кэширует результат на 11 часов. Статический `YANDEX_IAM_TOKEN` остаётся запасным вариантом.
- **Ограничение контекста:** 32 768 токенов. Требует чанкинга для длинных документов.
- **Для Router:** Нужен механизм явного указания URI в базе данных.

## 2. GigaChat (Сбер)

- **Совместимость:** Частичная. Прямой OpenAI SDK не работает. Нужен прокси-слой (например, `gpt2giga`).
- **Авторизация:** OAuth-токен со сроком жизни 30 минут. Требуется автообновление.
- **Function Calling:** Возвращает максимум 1 вызов за ход (нужно "схлопывать" параллельные вызовы).
- **Мультимодальность:** Принимает изображения, аудио и PDF прямо в запросе.
- **Ценообразование:** Одинаковая цена для input и output.

## 3. Архитектурное решение

Наш `LlmRouterService` должен поддерживать кастомные адаптеры. Для GigaChat мы напишем прокси-слой, который будет преобразовывать наши стандартные запросы в формат GigaChat.
