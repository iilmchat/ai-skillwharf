# Спецификация: AgentOps и Наблюдаемость (OpenTelemetry GenAI)

**Статус:** Утверждено
**Дата:** 2026-11-13

## 1. Назначение

Обеспечить сквозную трассировку (tracing) действий агентов для точной атрибуции затрат (токеномика) и обнаружения деградации качества.

## 2. Стандарт OpenTelemetry GenAI

Все First-party Tools и Skills обязаны генерировать OTel-спаны с префиксом `gen_ai.*`.
Ключевые атрибуты для каждого вызова:

- `gen_ai.system` (например, `openai`, `gigachat`).
- `gen_ai.agent.id` (ID агента).
- `gen_ai.tenant.id` (ID клиента/владельца).
- `gen_ai.skill.id` (навык, который был вызван).
- `gen_ai.usage.cost` (стоимость в рублях).

## 3. Валидация при публикации

При публикации навыка в реестр (Skill Store) происходит проверка: если навык вызывает LLM, он должен возвращать эти атрибуты. Иначе он отклоняется (аналогично `skill-vetter`).
