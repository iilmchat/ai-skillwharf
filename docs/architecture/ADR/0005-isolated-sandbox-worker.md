# ADR 0005: Изоляция Sandbox Worker

**Статус:** Принято
**Дата:** 2026-11-13

## 1. Контекст

В ходе аудита было выявлено, что монтирование `/var/run/docker.sock` в контейнер API дает процессу Gateway root-эквивалент на хосте. Любая уязвимость в NestJS или Prompt Injection может привести к компрометации всей инфраструктуры.

## 2. Решение

Мы выносим исполнение недоверенного кода в отдельный микросервис `sandbox-worker`.

- **API (Gateway)** больше не имеет доступа к Docker Socket. Он общается с `sandbox-worker` по внутренней HTTP-сети (gRPC или REST).
- **sandbox-worker** принимает только код и лимиты, запускает его в изолированном контейнере (read-only, network=none) и возвращает stdout/stderr.

## 3. Последствия

- **Плюсы:** Компрометация API больше не дает доступа к хосту. Упрощается горизонтальное масштабирование воркеров.
- **Минусы:** Усложняется инфраструктура (добавляется один сервис). Появляется сетевая задержка при вызове инструментов.
