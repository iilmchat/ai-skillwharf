# Спецификация: Pay-per-Outcome (Оплата за результат)

**Статус:** Утверждено
**Дата:** 2026-11-13

## 1. Контекст

Рынок движется от Pay-per-Call к Pay-per-Outcome. Клиенты хотят платить за «обработанный возврат» или «сгенерированный и принятый отчет», а не за количество токенов.

## 2. Механизм Эскроу (Escrow)

В Billing Abstraction Layer добавляется трехфазная модель:

1. **Authorize (Hold):** При запуске навыка средства резервируются на балансе пользователя, но не списываются.
2. **Validate (Подтверждение):** Агент выполняет работу. Результат проверяется либо автоматически (по схеме), либо человеком (Human-in-the-Loop).
3. **Capture (Списание):** Если результат принят — средства списываются (`debit`). Если отклонен — средства возвращаются (`cancel`).

## 3. Обновление SKILL.md

В манифест добавляется секция `outcome`:

```yaml
pricing:
  model: "Pay-per-Outcome"
  price: 50.00
  outcome:
    validation_schema: "string" # Или JSON Schema
    requires_human_approval: true
```
